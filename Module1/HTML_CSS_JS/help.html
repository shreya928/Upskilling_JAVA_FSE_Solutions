Help & Support

Welcome to the CityConnect Community Portal Help Centre. Find answers to common questions and guidance on using the portal.

📋 How to Register for an Event

  1. Go to the Register section on the main page.
  2. Fill in your name, email, preferred date, and event type.
  3. Optionally enter your phone number and a message.
  4. Click Register Now to submit your registration.
  5. A confirmation message will appear on screen.

🔍 How to Filter Events

  • Use the Filter by Category dropdown to narrow events.
  • Type in the search box to find events by name.

📍 Geolocation

  • Click Find Nearby Events to share your location.
  • Your browser will ask for permission — please allow it.
  • Your coordinates will be displayed to find nearest events.

💾 Saved Preferences

  • Your preferred event type is saved automatically using localStorage.
  • It will be pre-selected next time you visit.
  • Click Clear Preferences to reset all saved data.
